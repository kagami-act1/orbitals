# OrbitRing 0.7 — Googleアイコンの選択

- Google FontsのMaterial Symbols Roundedを4,001種類同梱。元の4,301名称から、同一コードポイントの別名を統合しました。
- 各アイコンを18カテゴリのいずれか一つに分類。日本語の名称・用途、英語名、Googleの検索タグ、旧名称で検索できます。
- 詳細欄の「アイコンを変更」から、右端の専用選択画面を開きます。検索・カテゴリ・48個ずつのページ送り・スクロール・現在の大きな見本を用意しました。
- アイコン名は図柄の下に表示し、長い名称はツールチップで確認できます。選択後も一覧のスクロール位置を保ちます。
- 保存・取り消し・並べ替え・実際のリング表示に対応。旧24種類と自動選択も維持しています。
- ベクターを本体に埋め込み、利用時の通信・追加フォントのインストールは不要です。取得元・ライセンス・分類表を同梱しています。

82項目の内部検証が通過しました。4,001個すべての描画データ、重複と分類漏れ、検索、旧設定との互換性、JSON保存と並べ替えを確認しています。実画面で日本語検索、ページ送り、選択した図柄の編集リングへの反映、取り消しを確認しました。検証用の変更は取り消し、保存済み設定は維持しています。

## 0.6.3 — 説明文と安全性の見直し

- 左上の見出しを「リングの設定」に変更。「ドラッグで割り当て・並べ替え。項目をクリックして内容を編集。」と操作方法を一行で表示。
- 現在は使っていない旧リング編集処理と、重複していたキー送信処理を削除。
- ドラッグ中の情報をアプリ内部だけで保持。外部アプリから渡された独自形式のデータを取得・オブジェクト化する経路を削除。
- ファイル・URLの検証を保存時と実行時で共通化。存在する絶対パスまたは http(s) URLだけを受け付け、相対パス・デバイスパス・代替データストリーム・制御文字を拒否。URLの環境変数展開を停止。
- 設定ファイルのサイズ・JSON階層・キー文字数・マクロ文字数に上限を設定。
- WindowsのDLL読み込み元をSystem32に限定。
- 通常のショートカットも、既に押されているキーを解除しない送信処理へ統一。キー解除の失敗は記録を残して再試行。
- 予期しない画面処理エラーでもリングとキー保持を停止するよう変更。

2026年10月17日、警告なしでビルドし、69項目の内部検証が通過しました。実画面で見出し、リング内の入れ替え、一覧からの割り当て、取り消し、リング経由のCtrl+A入力を確認しました。検証用の編集は取り消し、保存済み設定を維持しています。

点検範囲と制約は「コード点検-0.6.3.md」に記載しています。

## 0.6.2 — 呼び出した位置でキーを保持

- キー保持アクションを選ぶと、カーソルをリングを呼び出した位置へ戻してからリングを隠します。呼び出した場所でホイール操作ができます。
- カーソルの位置を固定する機能ではありません。戻した後は自由に移動でき、左ボタンを離すとキーを解除します。
- 画面端に収める位置補正と自動縮小を撤去。見切れる場合も、呼び出した地点をリングの中心に保ちます。
- 表示領域をタスクバーを含むモニター全体へ変更しました。スタートメニューを避ける専用処理はありません。
- 保存済みの配置・サイズ・ショートカット・アクション設定は維持しています。

2026年10月17日、ビルドと既存の53項目の検証が通過しました。実画面で保持アクション選択後にカーソルを動かさず再呼び出しし、元の呼び出し位置へ戻ることを確認しました。画面上端でリングの中心を補正せず、上側が見切れる表示も確認しています。前版のブラウザでのキー保持とホイール動作はユーザーから動作確認をいただいています。この版の長押しとホイールの同時操作、および開いたスタートメニュー上での表示は自動操作では確認していません。

## 0.6.1 — キー保持中のホイール入力

- キー保持中にリングがマウスを捕まえ続け、ブラウザへホイールが届かない実装を修正しました。
- 保持開始時にマウスの捕捉を解除してリングだけを隠し、キーを保持したまま背後のアプリへ入力を渡します。
- 左ボタンを離す、Esc、呼び出しキー、操作先の切り替えでキーを解除します。非表示中も解除を監視します。
- 保持中はリング用の数字キー予約を解除します。
- 設定画面に、保持中はリングが隠れることを記載しました。登録済みのアクションはそのまま使えます。

2026年10月17日、ビルドと53項目の既存検証が通過しました。ブラウザ上での「左ボタンを保持しながらホイールを回す」同時操作は、自動操作ツールに押下状態を維持するAPIがないため未確認です。前版で確認した通常入力への復帰だけでは、この操作の検証として不十分でした。

## 0.6 — アクション編集とキー操作

- 戻す／進むをアイコン化し、やり直し履歴とCtrl+Y / Ctrl+Shift+Zを追加。
- サイズ調整欄の注釈を削除。呼び出しショートカットは右上の歯車へ移動。
- 配置したアクションをクリックすると、右端に詳細を表示。リングを覆わずに編集でき、一覧へ戻る矢印を用意。
- 斜め4方向を含め、ラベルの中心をリング中心からアイコンへ延びる線上に配置。
- 単独キー・ショートカットの記録、キーと待機時間を組み立てるマクロ、マウスで押している間のキー保持を追加。
- アイコンを24種類から選択可能。操作に合わせた自動表示にも戻せます。
- 呼び出しリング下の注釈と設定ボタンを削除。
- 呼び出し前に不透明度をゼロにし、現在のカーソル位置へ配置・描画してから表示。前回の位置の描画が一瞬見える問題に対応。閉じた後の古い表示予約も無効化。

2026年10月17日、実画面で以下を確認しました。

- 単独Ctrlの記録、スターアイコンへの変更、戻す／進む。
- マクロへの待機ステップ追加と順序変更。
- 検証用マクロによる「a → 待機 → b」の実入力。
- Ctrl保持アクションをマウスで押して離した後、通常の「c」入力ができること。
- 異なるカーソル位置でのリング呼び出しと、リング下の注釈・設定ボタンの非表示。

内部検証53項目が通過しています。キー解除、操作先変更での中止、部分送信失敗時の解除、マクロ順序と待機、入力済みキーの保護、アイコンの保存・交換などを含みます。異なるDPIの複数モニターでの表示とゲーム内操作は未検証です。

## 0.3 — キャンセル範囲

提供されたActions Ringの動画を参考に、外側へ動かしたときの選択・キャンセルを調整しました。

- ボタンを通り越しても、同じ方向の項目を選択し続けます。
- 外側の境界は、中心からボタンまでの距離の3倍を目安に設定しました。動画で選択が解除される位置からの推定値で、公式仕様の値ではありません。
- 中央へ戻す、または外側の境界を越えると、中央にピンク色で「× キャンセル」を表示します。その状態のクリックで閉じます。
- 移動だけでは閉じないため、そのまま項目の方向へ戻して選び直せます。
- ホバー表示とクリック判定で同じ範囲を使用し、クリック時の現在位置で選び直します。
- サイズ変更に合わせて範囲も拡大縮小します。ボタン単体のサイズ変更では範囲を変えません。

2026年10月16日、Windows上の75%表示で、ボタンより外の左上方向をクリックして「すべて選択」のプレビューが選ばれること、さらに外側のクリックと中央クリックで閉じることを確認しました。Escによる終了も確認済みです。実際のショートカットを送らないプレビューモードで検証しています。

## 0.2 — レイアウト編集

## 追加した操作

- リングの項目をドラッグして2つの配置を交換。
- 項目をクリックすると、右側の編集欄が選択した操作に切り替わる。
- リング全体（70〜140%）とボタンの大きさを別々に変更。
- 一回のスライダー操作を一回で取り消せる「ひとつ戻す」。
- 「保存内容に戻す」「標準の大きさ」。
- ドラッグの代わりに、左右の隣と入れ替えるボタン。
- 未保存の変更を表示し、編集画面を閉じるときに保存確認。

以前の設定ファイルもそのまま読み込めます。新しいサイズ項目がない場合は従来の大きさを使います。
