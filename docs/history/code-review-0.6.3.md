# OrbitRing 0.6.3 コード点検

2026年10月17日。対象は同梱のC#・XAML・ビルド設定。コード読解、ビルド、入力を送らない内部検証、実画面での操作確認を行いました。

## 修正

| 対象 | 見つかった問題・改善点 | 対応 |
|---|---|---|
| 旧編集処理 | LayoutEditorへ移行した後もRingSurfaceに古い編集・ドラッグ処理が残存 | 実行用リングから削除。配置検証も現行のLayoutEditorを対象に変更 |
| ドラッグ受け入れ | 独自形式を名乗る外部データをGetDataで取得する経路があった | OLE側のオブジェクトを読み取らず、同一プロセスが開始したドラッグの情報だけで編集。終了・例外時には情報を消去 |
| 起動対象 | 絶対パスという説明に反して相対パスも受理。URLにも実行時の環境変数展開を適用 | OpenTargetで保存・実行時の検証を共通化し、パスとURLを分離。シェルコマンドの組み立て・引数追加は行わない |
| 設定読込 | ファイル全体を読んでから解析。用途に対して大きい既定の解析上限 | 読み込み前に1MiB上限、JSONは256Ki文字・16階層に制限。ファイルは読込中に書き換えを許可しない共有モード |
| マクロ | 全ステップを解析した後で64個超過を判定 | 65個目を解析する前に拒否。4096文字上限、キーは48文字上限 |
| DLL | Windows API用のDLL検索元が明示されていなかった | System32のみを指定 |
| キー送信 | 通常操作と長押し・マクロの実装が別で、通常操作は既存の押下を守る処理がなかった | ActionPlaybackへ統一。通常操作でも他の押下キーを勝手に解除しない |
| 解除失敗 | 解除失敗を記録していても監視タイマーが停止し再試行されなかった | 未解除キーがある間は再試行し、新しいアクションを止める。警告の連続表示を抑制 |
| 画面処理エラー | 全体の例外処理でダイアログだけを表示 | ダイアログ前に実行・保持・リングを停止 |

## 確認結果

- ビルド成功、コンパイラー警告なし。
- 69項目の内部検証が成功。キーの解除失敗・再試行・既存押下の保護、不正なパスやURL、巨大・深い設定データ、64ステップの正常系を含みます。
- 実画面で説明文、項目同士のドラッグ、一覧からのドラッグ、取り消し、通常リングからCtrl+Aが送られることを確認。
- 検証のための編集は取り消し、保存ファイルを変更していません。

## 点検の範囲

この点検は、脆弱性が存在しないことを保証する監査ではありません。外部OLEデータの経路は攻撃コードの実行を試さずに除去しました。Windows/.NET本体や、登録したファイル・実行アプリ・ブラウザー拡張機能は監査対象外です。

ファイルやアプリを開く機能は維持しています。設定ファイルを書き換えられる人はアクションも変更できるため、この個人用アプリは設定ファイルの書き込み権限を信頼します。実行直前の存在確認後、対象ファイルそのものが入れ替えられる競合までは防ぎません。OSがキー入力を拒否し続ける状況で、解除の成功を保証することもできません。
