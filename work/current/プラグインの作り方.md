# Orbitalsの自作プラグイン

右上の歯車 →「プラグイン」→「プラグインを読み込む」でJSON定義を選び、「保存」します。planet・orbitのアクション一覧で「プラグイン」を選ぶと配置できます。同じIDのJSONを読み込み直すと定義を更新します。読み込むだけでは操作やプログラムを実行しません。

## ショートカットをまとめる

同梱の `plugin-examples/shortcuts/plugin.json` をコピーして編集してください。`Application` は対象アプリのexe名です。省略または空文字にすると全アプリで使えます。アプリごとのplanetの切り替えは既存の「アプリ」画面で設定します。

```json
{
  "SchemaVersion": 1,
  "Id": "my-notepad",
  "Name": "メモ帳の操作",
  "Application": "notepad.exe",
  "Actions": [
    { "Id": "save", "Label": "保存", "Icon": "ms:save", "Kind": "shortcut", "Value": "Ctrl+S" },
    { "Id": "select-copy", "Label": "すべてコピー", "Kind": "macro", "Value": "Ctrl+A\nCtrl+C" }
  ]
}
```

`Kind` は `shortcut`（キー）、`macro`（既存マクロと同じ形式）、`text`（定型文）、`program`（外部プログラム）の4種類です。`Id` は英小文字・数字・ハイフンを使う40文字以内の識別子、`Label` は20文字以内です。プラグインは16件、各プラグインは64アクションまでです。`Icon` は省略でき、既存の `ms:アイコン名` や自作画像の形式を使えます。

## コードでアプリと連携する

`plugin-examples/program` に、C#のソース・ビルドスクリプト・ビルド済みの小さなサンプルを同梱しています。最初は受け取ったアクションIDを通知するだけです。`Program.cs` の処理をアプリのAPI呼び出しなどに置き換え、同じフォルダーの `build.ps1` でexeを作り直せます。Windows標準の.NET Frameworkのコンパイラを使うため、Visual Studioは不要です。別の言語で作ったexeも同じ入出力形式で使えます。

```json
{
  "SchemaVersion": 1,
  "Id": "my-integration",
  "Name": "自作アプリ連携",
  "Actions": [
    {
      "Id": "example",
      "Label": "連携のサンプル",
      "Kind": "program",
      "Executable": "OrbitalsExample.exe",
      "Arguments": []
    }
  ]
}
```

exeは定義ファイルと同じフォルダー内に置き、`Executable` にそこからの相対パスを指定します。`Arguments` は文字列の配列で、それぞれを独立した引数として渡します。シェルのコマンド文字列としては解釈しません。

実行時に、標準入力へUTF-8のJSONを1行渡し、その後標準入力を閉じます。

```json
{"Version":1,"ActionId":"example","Application":"notepad.exe","WindowHandle":"123456","CursorX":800,"CursorY":450}
```

- `Application`・`WindowHandle`：リングやジェスチャーを呼び出した操作先のアプリとウィンドウ。ハンドルは10進文字列です。
- `CursorX`・`CursorY`：実行時のカーソル位置。物理ピクセルの画面座標で、複数モニターでは負値になる場合があります。
- 終了コード0は成功です。標準出力へUTF-8の文字を出すと、先頭240文字まで通知します。出力なしなら通知しません。
- 0以外は失敗です。標準エラーの先頭240文字までを通知します。UIへコマンドを送り返す仕組みはありません。

実行は最大2件、各30秒までです。制限時間やOrbitalsの終了で、Orbitalsが起動したプラグインのプロセスを停止します。プラグインがさらに起動した子プロセスの管理はプラグイン側で行ってください。長時間の常駐処理や、保持キーの押下・解放イベント、状態を継続して読む仕組みには現在対応していません。

連携先に使えるAPI・SDK・コマンドがあるかどうかで、実現できる操作は変わります。アプリが提供していない内部操作を自動的に使えるようにするものではありません。外部exeは通常のアプリと同じユーザー権限で動作します。別プロセスで動作しますが、権限を制限するサンドボックスではありません。

## 更新・バックアップ

JSON定義を変更したら、全体設定から読み込み直して「保存」してください。既に配置したアクションはIDで参照するため、同じIDの操作が更新されます。IDを変えたり操作を削除した場合は、配置し直してください。読み込み後にJSONだけを移動・削除しても登録済みの定義は残ります。

全体設定から無効化したり「登録を外す」こともできます。配置した枠はそのまま残り、無効な操作を実行すると通知します。

設定のJSONバックアップには登録した定義とexeの保存場所が含まれます。exe本体やソースは含まれません。別のPCへ移すときはプラグインのフォルダーも移し、そのPCで定義を読み込み直してください。Logitechのプラグインファイルとは別の形式です。
