# orbitals 1.0.0

Windows 11向けの個人用ランチャーです。リングを **planet**、マウスジェスチャーを **orbit** と呼びます。

## 起動・常駐

`orbitals-Setup.exe` を実行してインストールします。管理者権限は不要で、Windows 11標準の.NET Framework 4.8で動作します。インストール後はスタートメニューの「Orbitals」から起動できます。

- プログラムの標準保存先：`%LOCALAPPDATA%\Programs\Orbitals`
- 設定・バックアップ・未保存の下書き：`%LOCALAPPDATA%\Orbitals`
- 以前のZIP版を使っていた場合、セットアップの「設定の引き継ぎ」で、その `orbitals.exe` と `settings.json` があるフォルダーを選びます。元のファイルは残り、インストール版の設定がすでにある場合はそちらを優先します。
- 更新時はOrbitalsを終了してから新しいセットアップを実行します。設定は引き継がれます。
- 別アプリの仮想保存領域へ振り分けられる起動元では、Windowsの通常の起動環境で開き直し、保存先が分かれることを防ぎます。
- アンインストールはWindowsの「インストールされているアプリ」から行えます。設定ファイルは残るため、再インストール時にも使えます。

ZIP版も使用できます。展開したフォルダー内の `orbitals.exe` を起動し、`conversion` フォルダーも同じ場所に置いてください。ZIP版の設定は実行ファイルと同じフォルダーに保存します。

- 設定画面の右上の×で画面を閉じても常駐します。通知領域のアイコンを左クリックすると一時停止し、もう一度クリックすると再開します。停止中はアイコンが暗くなり、一時停止マークが付きます。設定は右クリック→「設定を開く」から開きます。
- 一時停止中はplanetの呼び出しキーとorbitの入力監視を止めます。再開しても、全体設定でOFFにした機能はOFFのままです。
- 「終了」は常駐も終了します。
- **右上の歯車 → 起動・管理 → Windowsにログインしたら自動起動 → 保存** で、次回から画面を出さずに常駐します。初期状態はOFFです。
- ZIP版で自動起動を使う場合は、展開したフォルダーを固定の場所に置いてください。移動するときは一度自動起動をOFFにして保存し、移動後にONにしてください。
- 設定ファイルは上記の設定保存先にあります。歯車 → 起動・管理の「バックアップを保存」からJSONにも書き出せます。

旧OrbitRingと同時には起動できません。

### 編集の保存と下書き

「保存」で実際の操作に反映します。編集中の内容は別の `settings.json.draft.json` に自動保存され、次に設定画面を開くと復元します。形が未登録のジェスチャーなど、編集中の内容も下書きに残せます。

未保存のまま閉じるときは、保存して閉じる・下書きで閉じる・破棄して閉じる・編集を続ける、から選べます。「下書きで閉じる」は実際の操作を変更しません。「保存内容に戻す」は編集内容を最後に保存した状態へ戻します。

## planet

呼び出しキーの初期値は **Ctrl+Alt+F9** です。マウスのボタンにも同じキーを割り当てます。呼び出した瞬間のカーソル位置を中心に表示し、画面端でも中心位置をずらしません。

- アクションをクリックして実行。1〜8キーでも選択できます。
- 中央・右クリック・Escで閉じます。リングの外側のキャンセル範囲でもキャンセルできます。
- 文字はアイコンにカーソルを重ねると表示します。
- **歯車 → 外観 → planet → 文字のみを表示** で、アイコンの代わりに名前を表示します。通常・スタック・変換の全リングに共通です。長い名前は折り返し、省略された名前は中央やツールヒントで確認できます。
- キー保持は左ボタンを押して選択すると呼び出し位置へカーソルを戻し、リングを隠してキーを保持します。左ボタンを離すかEscで解除します。

設定画面ではアクション一覧からドラッグして配置し、項目をクリックして右側で内容を変更します。編集用リングの大きさは実際の表示サイズに左右されません。実際に呼び出すリングとボタンのサイズは、歯車 →「外観」で変更できます。

編集用リングの空白や中央、リングの周囲を左クリックするとアクション一覧へ戻ります。配置や開いているスタックは変更しません。アクション、名前のラベル、拡大縮小ボタンをクリックした場合は、それぞれの操作を優先します。

ボタンの大きさは82pxを100%として表示します。以前に保存したボタンの大きさは維持します。

### 複数のplanet

編集画面左上で対象を選びます。「＋ planet」で空のリングを追加し、「管理」で名前・呼び出しショートカットを指定します。メインを含め8個まで作成でき、各ショートカットから直接呼び出せます。

「このplanetを複製」は配置をコピーします。複製元を変更してもコピーには影響しません。追加したplanetは管理画面で削除できます。リングの大きさと外観は全planet共通です。

### スタック

配置した項目を選び「このアクションをスタックにまとめる」を押すと、元のアクションを中に残してスタックにします。空のスタックは一覧から追加できます。

- 編集画面ではスタックをダブルクリック、または「スタックの中を編集」で開きます。
- 中でもドラッグで配置・並べ替えできます。スタックにアクションをドロップすると空き枠へ追加します。
- 配置したアクションは、アイコンや名前を右クリック →「消去」で外せます。スタックを消すと中身も外れます。「元に戻す」で復元できます。円状の配置は空き枠を残し、弧状の配置は間を詰めます。
- 階層型は8枠、弧状は32件まで追加できます。スタックは3階層まで。上限に達した場合は既存の内容を保持します。
- 配置したスタックを選び、右側の「開き方」で表示方法を選びます。「保存」で反映します。
- **次の階層へ切り替え**：リング全体をスタックの中身に切り替えます。既存のスタックはこの方式です。
- **外側に弧状に展開**：元のリングを残し、そのスタックの方向へ同心円状の弧を広げます。追加数に応じて項目が増え、8件を超えると外側に次の弧を作ります。空き枠は表示しません。開いたスタックをもう一度選ぶと閉じます。
- **右上の歯車 → 外観 → 弧状スタックの間隔** で、全弧共通の間隔を20〜400の範囲で調整できます。標準値は50で、以前の20pxに相当します。背景の円・弧の外縁から次の背景の外縁までの間隔で、複数段の弧や入れ子にも共通で適用します。以前に保存した実際の間隔は維持し、表示する数値だけを新しい基準に換算します。編集画面と実際のリングの両方に反映します。
- 中央・右クリック・Escで一段戻ります。表示方法を混ぜた入れ子にも対応します。1〜8キーは、いちばん奥に開いたスタックの先頭8枠に対応します。9番目以降はマウスで選択します。
- スタックは重ねた層のアイコンで表示し、通常のフォルダーと区別します。

編集画面でも開き方に合わせて表示します。弧状のスタックを選ぶと、親リングを残して外側へ展開します。外側の項目をクリックするとその項目を編集でき、同じスタック内でドラッグして並べ替えられます。「＋ 追加」は空き枠です。クリックしてアクションを選ぶか、一覧からドロップしてください。実際のリングでは空き枠を表示しません。

階層切り替え型はダブルクリックまたは「スタックの中を編集」で次のリングへ進みます。スタックは共通の重なった層のアイコンで示します。開き方は右側の設定欄で変更できます。入れ子でも開き方を組み合わせられ、「上の階層」で戻れます。弧状から階層型に変更するには、中のアクションを8件以下にしてください。

編集エリア右上の「＋」「−」は編集画面だけを拡大・縮小し、「全体を表示」で元に戻します。Ctrl＋ホイールでも拡大・縮小でき、中央ボタンを押したままドラッグすると表示を移動できます。実際に呼び出すリングのサイズや配置データは変わりません。

右上の歯車 → 外観にある「リングを開くときの演出」で、表示時の演出をON/OFFできます。標準はONです。「演出を試す」で同じ画面のリング上に表示して確認できます。最初の描画から約0.42秒間、中心と半径を固定した同心円状の光が等速で回転し、薄くなって消えます。planet本体も、最初から見える状態で濃さが整い、背景と輪郭に柔らかな光が重なってから通常の色へ戻ります。色はリングの強調色に合わせます。アイコン・本体・クリック判定の位置と大きさは固定し、表示直後から操作できます。Windowsのアニメーションが無効の場合は、実際のリングでは演出しません。

### 自作プラグイン

右上の歯車 →「起動・管理」→「プラグイン」からJSON定義を読み込み、「保存」で登録します。アクション一覧の「プラグイン」に表示され、planetとorbitへ配置できます。アプリ専用のショートカット・マクロ・定型文、外部プログラムを使った連携に対応します。作成方法は同梱の「プラグインの作り方.md」と「plugin-examples」を参照してください。

## orbit

同じ設定ウィンドウの **orbit** タブで設定します。初期状態は右ボタンを押して描き、離して実行します。普通の短い右クリックはそのまま使用できます。Escでキャンセルします。

| 動き | 初期アクション |
|---|---|
| ← / → | 戻る / 進む |
| ↑↓ | 再読み込み |
| ↓→ / ↓↑ | タブを閉じる / 閉じたタブを戻す |
| ↑ / ↓ | 最大化・元に戻す / 最小化 |
| 右ボタン＋ホイール↑ / ↓ | 開始位置で拡大 / 縮小 |
| 右ボタン＋左クリック | 次のタブ |

planetと同じく、中央で対象を選び、右側でアクションを割り当て・編集します。中央下部に登録したジェスチャーの図と名前を表示し、選んだ形を中央で大きく確認できます。「＋追加」で、プリセットか自作ジェスチャーを選べます。

形の描き直しと補正は、図の右上にある「編集」を押してから変更します。「動きの種類」と「同時に押すキー」は、編集モードに入らず変更できます。ホイールや左クリックから描画へ切り替えると、そのまま形を描けます。描画中のカーソルは十字です。「完了」で描き直しを終了し、「保存」で反映します。通常はドラッグしても形を変更しません。別の項目や画面へ移ると編集を終了します。

形で認識するジェスチャーには、それぞれ「許容するずれ」を設定できます。形の編集を始めず、そのままスライダーで調整できます。5〜35％の範囲で、小さい値ほど登録した形に近いときだけ実行します。初期値は16％です。認識テストでは、入力した形のずれと各登録の許容値を比較できます。ホイールや左クリックの組み合わせには、この設定はありません。

右のアクション一覧から中央やジェスチャー項目へドラッグして割り当てられます。クリックで選択中の項目に割り当てる操作、項目をクリックして右側で内容を変更する操作、元に戻す・やり直しはplanetと共通です。アイコン変更はplanet専用です。orbitはジェスチャーの形で識別します。

「保存して試す」は、planetではリングを表示し、orbitでは設定画面を最小化してジェスチャーを試せる状態にします。

「同時に押すキー」はCtrl・Alt・Shiftを押しながら描く条件です。「なし」なら開始ボタンだけで実行できます。「動きの種類」でホイールや左クリックとの組み合わせも選べます。開始ボタン・反応するまでの移動距離は歯車 →「操作」、軌跡の表示や色は歯車 →「外観」で設定します。

「右ボタン＋左クリック」は、**右ボタンを押したまま左クリックする**操作です。設定画面の外で使います。初期状態では「次のタブ」を実行します。ホイール操作も開始ボタンを押したまま使います。マウス図の上下矢印で回す方向を区別できます。

丸・斜線・W字など、一筆書きの形を保存して認識できます。描く位置・大きさ・速度の違いを補正し、向きと描く順番を区別します。描き始める場所と順番は登録時に合わせてください。図の点は始点です。

図や一覧の項目にカーソルを重ねると、矢印が描く順番をたどります。尾は終点でも減速せず、同じ速さで先端まで追いつきます。短い図でも見える長さと時間を確保し、形の表示サイズは変えません。カーソルを離すか、画面が非アクティブ・非表示になると停止します。Windowsのアニメーションが無効なら静止表示です。保存データと認識用の形には影響しません。複数回に分けた描画、スクリプト実行、StrokesPlus設定のインポートには対応していません。

「自動で補正」がONなら、新しく描いた形の手ぶれや凹凸を抑えて登録します。直線・明確な角と、弧・曲線を区別し、曲線を45度刻みの折れ線へ変えないようにしています。円に近い弧は弧として整え、交差するループやS字も滑らかにします。描く順番と大きな特徴は維持します。「補正前に戻す」で元の描画へ戻せます。元の描画も保存するため、再起動後も戻せます。

既存の手描きジェスチャーに新しい補正を適用する場合は「自動で補正」を一度OFFにし、ONにしてください。元の描画から補正し直すので、繰り返しても変形が蓄積しません。細かい特徴を優先したい場合はOFFで登録してください。

### プリセット

「＋追加」→「プリセットから選ぶ」で、27種類の動きを選べます。W・Z・N・逆V・○の右回り／左回りも用意しています。直線・往復・折れ線・曲線・ホイール・クリックの順にまとめ、名前でも検索できます。自作の形は最も近い分類に置き、曲線と角を組み合わせた形などは「複合」にまとめます。「標準／自分のプリセット」は動きの種類とは別に絞り込めます。図にマウスを重ねると描く順番を確認できます。

- 動きだけを追加します。実行する内容は未割り当てなので、右側のアクション一覧から選んでください。未割り当てのまま保存しても、操作は実行しません。
- 削除後もプリセット一覧から追加し直せます。
- 同じ形と同時に押すキーが登録済みなら、現在の設定を開きます。変更済みのアクションを上書きしません。
- 追加後は形・同時に押すキー・アクションを変更できます。プリセットの元データは変わりません。

登録したジェスチャーを選び「プリセットに保存」を押すと、「自分のプリセット」に追加できます。形と操作条件だけを保存し、実行するアクションは含めません。64件まで保存でき、元のジェスチャーを削除しても再利用できます。プリセット一覧で自分のプリセットを削除しても、配置済みのジェスチャーは残ります。

### 認識テスト

「認識テスト」を押し、中央へ左ドラッグで描くと、一致した登録と似た形を確認できます。アクションは実行せず、登録した形も変更しません。「同時に押すキー」でテストする条件を選び、「テスト終了」で通常の編集へ戻ります。マウスの開始ボタン・ホイール操作を含めて試す場合は「保存して試す」を使ってください。

似た形が複数ある場合や登録した形から大きく外れた場合は実行しません。形を分かりやすく描き直すか、「同時に押すキー」で区別してください。以前の方向ジェスチャーも引き続き使えます。

StrokesPlus.netなどと同じボタンで同時に監視すると競合します。併用する場合は開始ボタンを分けてください。

## ブラックリスト

**アプリ → ブラックリスト** に、planetやorbitを使わないアプリを登録します。実行ファイルを選ぶか、`vivaldi.exe` などの名前を入力し「＋追加」を押してください。

- 「planetを使う」「orbitを使う」を個別に切り替えます。両方OFFなら、登録したアプリが前面にある間はどちらも反応しません。通常のマウス操作はそのまま使えます。全体設定でOFFの機能は、ここでONにしても動作しません。
- リストにないアプリではplanet・orbitを使用できます。専用設定があればその内容を、なければ共通設定を使います。
- 「解除」でリストから外すと、再び使えるようになります。変更は「保存」で反映します。
- 「現在のアプリを除外」アクションからも追加できます。実行ファイル名は大文字・小文字を区別せず、64件まで登録できます。

## アプリ別設定

**アプリ** タブから登録します。実行ファイル名を入力する、exeを選ぶ、起動中のアプリから選ぶ、のいずれかで指定できます。32件まで登録でき、大文字・小文字は区別しません。専用設定の有無と、planet・orbitをこのアプリで使うかどうかは別々に指定できます。

- planetとorbitの専用設定を、それぞれON・OFFにできます。専用設定がOFFの機能や未登録のアプリでは、現在の共通設定を使います。
- 「planetを編集」「orbitを編集」で専用設定を開きます。初回は共通設定のコピーを作るため、実行内容・形・閾値などをそのアプリ専用に変更できます。専用設定をOFFにしても編集内容は残り、再びONにすると戻せます。
- 編集中のアプリ名を画面上部に表示します。「共通設定を編集」で共通の編集に戻れます。専用設定のON・OFFは変わりません。
- planetは呼び出した瞬間、orbitは開始ボタンを押した瞬間にアクティブだったアプリを使います。アプリ専用のジェスチャー一覧は共通一覧を置き換え、専用一覧にない動きは実行しません。ブラックリストは専用設定より優先します。
- 複数planetの名前・呼び出しキー・追加削除、リングのサイズ・外観、orbit全体の入力設定は共通です。planetごとの配置と、orbitの動き・実行内容はアプリ別に編集できます。
- 同じ実行ファイルのウィンドウは共通の専用設定を使います。ウィンドウのタイトルによる区別はしません。変更は「保存」で反映し、下書き復元・元に戻す・JSONバックアップにも対応します。

## 全体設定・外観・JSONバックアップ

右上の歯車から開きます。上部のタブはplanet・orbit・アプリ・変換の4つで、ブラックリストはアプリ内にあります。

歯車内は、左側の3分類から選びます。

- **操作**：planet・orbitのON / OFF、リングの呼び出しキー、ジェスチャーの開始ボタン・移動距離。
- **外観**：リング全体・ボタンのサイズ、色・濃さ・弧の間隔・文字表示・演出、ジェスチャーの軌跡表示・色・太さ・長さ。
- **起動・管理**：Windowsへのログイン時の起動、ファイル変換の履歴・詳細、プラグイン、JSONバックアップ・復元。

タブで各機能へ切り替えます。アイコン選択は「完了」で元の設定へ戻り、アクション詳細の「アクション一覧」で一覧を開けます。

- **機能のON / OFF**：planet（リング）とorbit（ジェスチャー）を個別に切り替え、「保存」で反映します。OFFにしても配置やジェスチャーは残ります。通知領域のメニューからも直接切り替えられます。
- planetがOFFの間は呼び出しショートカットを解除し、orbitがOFFの間はジェスチャー用の入力監視を停止します。ファイル変換は独立して利用できます。
- キー指定は記録操作に統一しています。表示されているキーは手入力できません。定型文やマクロの待ち時間などは、これまでどおり入力できます。
- **キーを記録**：ボタンを押し、割り当てるキーを押して離します。記録中はplanetの呼び出しを停止します。Esc、別の画面への移動、他のアプリへの切り替えで中止します。アクションのキー保持にはCtrlなどの単独キーも指定できます。

### 更新

右上の歯車の左隣にある更新アイコンから確認します。現在のバージョンと確認結果を小さなパネルに表示します。

- ボタンを押したときだけ確認します。定期的な自動確認は行いません。公開先は配布版の設定を使うため、入力は不要です。
- 新版があれば「更新ページを開く」を表示します。通常の編集画面や全体設定には更新情報の入力欄を置いていません。
- 配布ファイルを含む正式リリースを対象にします。下書き・試験版・現在以下のバージョンは通知しません。公開リポジトリに対応し、認証トークンは保存しません。
- 更新確認ではGitHubのリリース情報だけを取得します。個人設定やファイルは送信しません。
- 更新時はOrbitalsを終了してからセットアップを実行します。ZIP版は既存の `settings.json` を保持してファイルを差し替えてください。配布ファイルには個人の設定・バックアップ・下書き・ソースコードを含めません。

### 外観とバックアップ

- **外観**：歯車の「外観」に、planetとorbitの設定を並べています。リングの強調色・濃さ・間隔・表示演出は1つのデモで確認できます。色はパレットまたは `#RRGGBB` で指定します。orbitでは軌跡の表示・色・太さ・残す長さを変更でき、長さが「すべて表示」の場合、ジェスチャー全体の軌跡を残します。
- プレビューへ色と太さがすぐ反映されます。実際の操作には「保存」で反映します。「外観を標準に戻す」で初期値へ戻せます。
- **弧状スタックの間隔**：背景の円と弧、弧同士の外縁からの距離です。入れ子や複数段でも同じ間隔になります。デモには初めから1つの弧状スタックを表示します。間隔を変えても倍率とリングの中心は変わりません。実際のアクション構成は変更しません。
- **バックアップを保存**：複数のplanet・スタック・ジェスチャー・自分のプリセット・お気に入り・外観・ブラックリスト・アプリ別設定などを、通常の `.json` ファイルにまとめます。
- **バックアップから復元**：バックアップや既存の `settings.json` を選ぶと、検証後に編集画面へ読み込みます。「保存」で実際の設定に反映します。「元に戻す」も使えます。
- 起動・呼び出しキーもバックアップに含まれます。別のPCで読み込む場合、登録したファイルやアプリのパスはそのPCに合わせてください。

## アクション

キー、キー保持、マクロ、多段階トグル、ファイル・URL、ウィンドウ配置、タブ操作、アプリ起動・前面化、定型文、選択文字の検索、書式なし入力、音量、マイクミュート、音声出力先の選択などを割り当てられます。

トグルは各段階の操作・名前を指定し、「＋」で段階を増やします。planetでは各状態のアイコンも指定できます。音量とマイクのミュートは実際のWindowsの状態と同期します。汎用トグルはorbitals内の状態で循環するため、他アプリ側の変更とは自動同期しません。

「音量（ホイール）」「ミュート切替」「マイクのミュート切替」を選ぶと、詳細画面の「状態ごとのアイコン・文字列」で、ミュートON・OFFそれぞれの表示を指定できます。Googleのアイコン、自作画像、文字列から選べます。「操作に合わせて自動選択」に戻す操作も状態ごとに行えます。以前に配置した音量やマイクも、そのまま状態表示に対応します。

マイクの対象はWindowsの既定の通信用入力機器です。新しく追加する「マイクのミュート切替」はON・OFFの2段階トグルです。個別のトグル段階にマイクを指定する場合も、「ミュートON」「ミュートOFF」「ミュートを切り替え」から選べます。ON／OFFの2段階なら外部で切り替えた状態にも同期します。

標準アクションは90件です。用途が固定された操作と、自分で内容を作る操作を分け、各項目を次のいずれか1分類にまとめています。

| 分類 | 主な内容 |
|---|---|
| 編集・入力 | コピー、貼り付け、履歴、検索、定型文、日付・時刻 |
| 移動・タブ | 戻る、進む、タブ、再読み込み、アドレス欄、親フォルダー |
| スクロール・ズーム | 縦横スクロール、拡大・縮小、倍率リセット、ページ先頭・末尾 |
| ウィンドウ・デスクトップ | 配置、中央へ移動、サイズ指定、モニター、仮想デスクトップ |
| 音声・メディア | 全体・対象アプリの音量、ミュート、出力機器、再生操作 |
| ファイル・アプリ | ファイル・フォルダー・URLを開く、アプリの起動・前面化 |
| Windowsのツール | キャプチャ、検索、通知、設定、タスクマネージャー、ロック |
| カスタム操作 | キー指定、キー保持、トグル、マクロ、スタック |
| orbitals | 一時停止、現在のアプリをブラックリストへ追加 |

### お気に入り

配置したアクションを選び、右側の「お気に入りに保存」で内容を再利用できます。アクション一覧の上部で「標準アクション」「お気に入り」を切り替えます。両方とも同じ用途分類と検索を使えます。

お気に入りは64件までです。配置すると独立したコピーになり、元の内容を変更・削除しても配置済みのアクションは変わりません。スタックはplanetで使用します。

### キー操作の記録

マクロを選び、右側の「連続したキー操作を記録」を押します。3秒後に記録を開始するので、操作するアプリへ移ってください。F12または上部の「完了」で取り込み、Escまたは「中止」で取り消します。

キーの組み合わせと待ち時間を記録します。マウス操作や入力した文章の文字起こしは含みません。最大60秒・待ち時間を含め64ステップです。記録後はキーや待ち時間を個別に変更でき、「保存」で反映します。F12・Escは記録を終了するために使用し、マクロへは含めません。

### 音声・ウィンドウなど

- **対象アプリの音量**：操作を始めたときのアプリを5％ずつ調整、またはミュートします。音声が見つからない場合は、対象アプリで音を再生してから試してください。
- **音声出力先を直接切替**：接続されている再生機器を選んで登録します。複数段階トグルの各段階にも別々の出力機器を指定できます。既定の通話機器は変更しません。
- **音声出力先の選択画面**：Windows 11標準の機器選択画面を開きます。マイクミュートは既定の通信用マイクが対象です。
- **ウィンドウのサイズ指定**：`1280x720` のように幅と高さをpxで入力します。作業領域に収まるよう調整し、中央へ配置します。アプリ側の最小サイズなどにより指定通りにならない場合があります。
- **左右スクロール**：操作開始位置へカーソルを戻して、横ホイールの入力を送ります。対象アプリが横スクロールに対応している必要があります。
- **日付・時刻**：実行時点の値を入力します。日付は `yyyy/MM/dd`、時刻は `HH:mm` です。
- **画面キャプチャ**：PrintScreenを送ります。Windowsの設定によって切り取り画面が開く場合があります。

管理者権限で動くアプリなどにはキー入力が届かない場合があります。

標準アクションの自動アイコンにはGoogle Material Symbolsを使用します。フォルダーとエクスプローラーにはフォルダー記号、スタックには層を重ねた記号を使い、編集画面・アクション一覧・実際のリングで揃えています。手動で選んだアイコンは自動アイコンより優先します。Google Material Symbolsの4,001アイコンを同梱しており、選択時の通信は不要です。分類は `アイコン分類.md`、ライセンスは `THIRD-PARTY-NOTICES.txt` を参照してください。

### 自作のアイコン

planetで配置済みのアクションを選び、**アイコン・文字列を変更 → 画像ファイルから選ぶ…** で指定します。選択画面は編集エリア全体に広がり、検索・カテゴリ・ページ切り替えで選べます。PNG・JPEG・ICO・BMP・GIFに対応します。GIFは静止画として取り込みます。

- 縦横比と透過を保ち、最大128pxに縮小して設定内へ保存します。元画像を移動・削除しても表示できます。
- 元画像は4MB以内、縦横4096px以内です。小さく表示するため、余白が少なく輪郭がはっきりした画像を選ぶと見やすくなります。
- スタックや、トグルの初期状態・各段階にも指定できます。状態ごとに「この状態のアイコンを変更」から選びます。
- お気に入り・下書き・JSONバックアップにも画像を含めます。別途画像ファイルを添付する必要はありません。
- 「操作に合わせて自動選択」で標準アイコンへ戻せます。Googleアイコンを選び直すこともできます。

変更後は「保存」で実際のリングへ反映します。orbitはジェスチャーの形で識別するため、アイコンの変更はplanet専用です。

### アクションごとに文字列を表示する

通常のplanet・スタック・トグルの各状態・変換先では、**アイコン・文字列を変更 → 表示するもの「文字列」** を選べます。1〜16文字で入力し、右側の丸いボタンの見本を確認して「この文字列を使う」を押します。アクションの名前と実行内容を変えず、例えば「COPY」「PDF」「ON」などを個別に表示できます。文字とアイコンを同じリングに混在できます。変更後は「保存」で反映します。

アイコンへ戻すときは、同じ画面で「アイコン」に切り替え、一覧・画像ファイル・自動選択から選び直します。通常のplanetでは左上の戻るボタンで詳細編集へ戻り、変換先では選択後に詳細編集へ戻ります。

## ファイルをドラッグして変換

1. 画像・PDFを左ボタンでつかみ、ドラッグを始めます。
2. 押したまま、planetの呼び出しキー（初期値 **Ctrl+Alt+F9**）を押します。マウスに割り当てた同じキーでも呼び出せます。
3. ファイルの種類に対応した変換先が表示されます。
4. 目的のplanetの上で左ボタンを離すと変換します。

画像では **PDF・PNG・JPEG・WebP・TIFF・BMP・GIF・ICO** を選べます。PDFでは複数の画像を1つにまとめます。
PDFでは **PNG・JPEG・WebP・TIFF・BMP・GIF** へ1ページずつ画像化するほか、ページごとの分割、複数PDFの結合を選べます。結合はPDFを2件以上つかんだ場合に表示します。

元のファイルは移動・削除しません。同じ名前の出力には連番を付けます。中央や形式のない場所で離すとキャンセルします。別のモニターへ移動して離してもキャンセルします。Escでは表示を消し、ボタンを離すまでキャンセル用の領域を残します。

保存先の固定設定はありません。元ファイルの場所が分かる場合は同じフォルダーに保存します。ブラウザー内の画像や一時ファイルなど、元の場所がない場合は、その都度保存先を尋ねます。異なるフォルダーから複数のファイルをまとめてドラッグした場合も保存先を尋ねます。保存先の選択を取り消すと変換しません。

### 変換先を編集する

上部の **変換** 画面で「画像をつかんだとき」「PDFをつかんだとき」を選びます。planetをドラッグするか、右側の「前へ」「次へ」で順番を変えられます。表示／非表示・名前・Googleアイコンまたは自作アイコン・画質・長辺の上限・PDFの画像化の解像度を編集し、**保存**で反映します。通常のリングの大きさを変えても、編集画面は大きく表示します。

「＋ 変換先を追加」で形式を選び、画像・PDFごとに32件まで登録できます。同じ形式を複数置き、名前・画質を分けることもできます。項目を右クリック →「消去」、または右側の「この変換先を削除」で外します。「元に戻す」で復元できます。削除した項目は再起動しても戻りません。すべて削除した場合も、同じ追加ボタンから登録し直せます。

表示する件数に合わせて円周上へ均等に並べます。少ないと間隔が広がり、多いと間隔とボタンが小さくなります。表示方法は通常のplanetと共通で、外観設定で文字のみの表示も選べます。

JPEG・WebPには画質、画像化には長辺の上限、PDFの画像化には解像度を設定できます。ICOは16・32・48・256pxを1つに含むアイコンファイルとして保存します。GIF・複数ページTIFFの入力は先頭の画像を使い、GIFの出力は静止画になります。JPEG・BMPでは透明部分が白になります。PDFの画像化は1回に1000ファイルまでです。

planet・orbitの「ファイル変換」アクションから先に変換先を出し、形式をクリックしてファイルを選ぶ方法も使えます。形式を指定したアクションでは、その形式だけを表示します。

### 処理中・完了した変換を確認する

変換を始めると進捗とキャンセルを表示します。完了後は保存先を開けます。**歯車 → 起動・管理 → ドラッグして変換 → 変換の履歴** または通知領域の **変換の履歴** から、直近15件の結果・保存先・エラーを確認できます。履歴は終了時に消えます。

画像の取り込みは別スレッドで、変換はPC内の別プロセスで実行します。ドラッグ変換は3件まで受け付け、変換本体を1件ずつ処理します。1回の入力は128ファイル・合計512MBまでです。非対応のファイルや、画像とPDFの混在は変換できません。画像データを渡せないアプリでは、画像をファイルに保存してからドラッグしてください。

### PDFの結合・ページ抽出など

**歯車 → 起動・管理 → ドラッグして変換 → PDFの結合・ページ抽出など** では、ファイルを選んで順番や対象ページを細かく指定できます。ページは `1,3-5` のように入力します。

## アプリで表示するplanet

「アプリ」画面で実行ファイルを指定し、その横の「表示するplanet」を選びます。登録後も、アプリ名の横で変更できます。メインの呼び出しキーを押すと、アクティブなアプリに指定したplanetを表示します。各planetの専用の呼び出しキーは、そのplanetを直接開きます。

「切り替えない」では呼び出したplanetを使います。アプリ専用に内容を変えたい場合だけ「planetを専用設定にする」「orbitを専用設定にする」を使います。ブラックリストの除外が優先されます。

planetの名前は、planet画面で対象を選んで「管理 → 名前」から変更できます。メインも変更でき、アプリとの対応付けは維持されます。割り当てたplanetを削除すると、そのアプリは「切り替えない」に戻ります。

### SVG・文字認識

SVGも画像としてドラッグでき、PNG・JPEG・WebP・PDFなどに変換できます。変換先の長辺を指定するとSVGの出力サイズを変更できます。外部ファイルやWeb上の画像・書体への参照には対応していません。画像をSVG内に埋め込み、書体はパスに変換してください。

画像・スキャンPDFでは「TXT」「文字をコピー」を選べます。Windowsの表示言語に対応するOCRで、PC内で文字を認識します。「TXT」は元ファイルと同じ場所にUTF-8で保存し、元の場所がないときだけ保存先を尋ねます。「文字をコピー」は保存先を尋ねず、認識した文字をクリップボードへコピーします。PDFはページ順に認識し、詳細画面では対象ページも指定できます。
