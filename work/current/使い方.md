# Orbitalsの使い方

Orbitalsは、リングランチャー **planet** とマウスジェスチャー **orbit** を使って、よく使う操作を呼び出すWindows 11向けアプリです。

## 1. 起動・常駐・保存

### インストールと起動

[ダウンロードページ](https://github.com/kagami-act1/orbitals/releases/latest)から、Windows 11・64bit向けの配布ファイルを取得します。

- **インストーラー版**：`orbitals-Setup.exe` を実行して保存先を選びます。管理者権限は不要です。インストール後はスタートメニューの「Orbitals」から起動します。
- **ポータブル版**：`orbitals-Portable-Windows11.zip` を展開して `orbitals.exe` を起動します。設定も同じフォルダーに保存するため、移動するときは展開したフォルダー全体を移してください。

ポータブル版からインストーラー版へ移行する場合は、セットアップの「設定の引き継ぎ」で、ポータブル版のフォルダーを選びます。インストーラー版に設定がある場合は、その設定を優先します。

### 常駐・一時停止・終了

設定画面の右上の **×** で閉じても常駐します。スタートメニューの「Orbitals」、または通知領域の右クリック →「設定を開く」で開き直せます。

- 通知領域のアイコンを左クリックすると一時停止し、もう一度クリックすると再開します。
- 常駐も終了する場合は、通知領域を右クリック →「終了」を選びます。
- 自動起動は、右上の歯車 →「起動・管理」→「Windowsにログインしたら自動起動」をONにして保存します。ポータブル版では、展開したフォルダーを固定の場所に置いてください。

### 編集した内容を保存する

画面下部の **「保存」** で操作に反映します。「保存して試す」では、保存後にリングやジェスチャーを試せます。

未保存のまま閉じる場合は、保存・下書き・破棄などを選べます。下書きは次回の編集時に復元されますが、実際の操作には反映しません。「保存内容に戻す」は、編集内容を最後に保存した状態へ戻します。

## 2. planet ― リングランチャー

### 呼び出す・実行する

初期の呼び出しキーは **Ctrl+Alt+F9** です。マウスのボタンに同じキーを割り当てて使うこともできます。リングは呼び出した瞬間のカーソル位置を中心に開きます。

- 項目をクリックすると実行します。数字キーでも表示順に選べます。
- 中央・右クリック・Escで閉じます。リング外側のキャンセル範囲でも閉じられます。
- 項目にカーソルを重ねると、外側に名前を表示します。
- 「キー保持」は左ボタンを押して選ぶと、カーソルを呼び出し位置へ戻してキーを保持します。そこでホイール操作ができます。左ボタンを離すかEscで解除します。

呼び出しキーは、歯車 →「操作」で変更します。「キーを記録」を押し、割り当てるキーを押して離してください。記録中は入力欄がハイライトされます。Escで中止できます。

キーボードにないPause／BreakやF13〜F24は「キーを選ぶ」から指定できます。文字キーや矢印などの単独キー、修飾キー単独は呼び出し用に指定できません。Windowsや他アプリが使っているキーは登録できない場合があります。

### 配置と内容を編集する

「planet」タブで、右側のアクション一覧からリングへドラッグして配置します。配置した項目をクリックすると、名前や実行内容を変更できます。

- アイコンや名前をドラッグして移動します。使用中の枠へ重ねると入れ替えます。
- 項目を右クリック →「消去」で外します。円状の配置では空き枠を残します。
- 中央や何もない場所をクリックすると、アクション一覧へ戻ります。
- 「元に戻す」「やり直す」で編集を取り消し・再適用できます。

編集用リングは、実際の呼び出しサイズに関係なく大きく表示します。「＋」「−」やCtrl＋ホイールで拡大・縮小し、「全体を表示」で表示範囲を戻せます。中央ボタンを押したままドラッグすると表示を移動できます。

### 複数のplanetを使う

左上で編集するplanetを選びます。「＋ planet」で追加し、「管理」で名前の変更・複製・削除を行います。メインを含め8個まで作れます。

リングを呼び出し、中央でホイールを回すとplanetを切り替えられます。下で次、上で前です。スタック内では切り替えず、音量アクション上では音量調整を優先します。

追加planetの個別ショートカットは初期状態がOFFです。直接開くキーを付ける場合だけ、「管理 → 個別ショートカットを使う」をONにして記録・保存します。

アプリ専用に指定したplanetは、通常のホイール切り替えの対象から外れます。アプリとの対応付けは「アプリ」タブで行います。

### スタックにまとめる

複数の操作をまとめる機能です。項目を選んで「このアクションをスタックにまとめる」を押すと、元の操作を中に残してスタックにします。空のスタックを一覧から配置することもできます。

| 開き方 | 表示 |
| --- | --- |
| 次の階層へ切り替え | リング全体をスタックの中身に切り替えます。 |
| 外側に弧状に展開 | 元のリングを残し、外側へ弧状に操作を並べます。 |

編集画面では、ダブルクリックまたは「スタックの中を編集」で中を開きます。リングとスタックの間で直接ドラッグして移動できます。スタック本体へ離すと、中の空き枠へ追加します。

階層型は8枠、弧状は32件までで、入れ子は3階層までです。弧状の項目を消すと間を詰めます。間隔は歯車 →「外観」で、見本を確認しながら調整できます。

実際の操作では中央・右クリック・Escで一段戻ります。

## 3. orbit ― マウスジェスチャー

### 基本操作

初期設定では、**右ボタンを押しながら動かし、離す**と実行します。普通の短い右クリックはそのまま使えます。Escでキャンセルできます。

| 動き | 初期アクション |
| --- | --- |
| ← / → | 戻る / 進む |
| ↑↓（上へ動かして戻る） | 再読み込み |
| ↓→ | タブを閉じる |
| ↓↑ | 閉じたタブを戻す |
| ↑ / ↓ | 最大化・元に戻す / 最小化 |
| 右ボタン＋ホイール↑ / ↓ | 開始位置で拡大 / 縮小 |
| 右ボタンを押したまま左クリック | 次のタブ |

### 動きと実行内容を設定する

「orbit」タブでジェスチャーを選び、右側のアクション一覧から実行内容を割り当てます。

「＋追加」から、プリセットまたは自作の形を選べます。プリセットは動きだけを追加するため、実行するアクションも選んでください。削除したプリセットは追加し直せます。

- **形を描き直す**：図の「編集」を押して描き、「完了」で終了します。自動補正と「補正前に戻す」も使えます。
- **動きの種類**：描画・ホイール・左クリックの組み合わせを選びます。
- **同時に押すキー**：Ctrl・Alt・Shiftなどを押しながら操作する条件です。「なし」なら開始ボタンだけで操作します。
- **許容するずれ**：形の判定を調整します。小さいほど登録した形に近い場合だけ実行します。
- **プリセットに保存**：自作の形と操作条件を再利用できます。実行するアクションは含みません。

「認識テスト」では、中央に描いた形と登録した形を比較できます。アクションは実行しません。実際のマウス操作で試すときは「保存して試す」を使います。

開始ボタンと反応するまでの移動距離は歯車 →「操作」、線の色・太さなどは歯車 →「外観」で変更します。

### ジェスチャーからplanetを開く

アクション一覧の「orbitals → planetを開く」を割り当て、実行するplanetを選んで保存します。開始ボタンを離すと、その時のカーソル位置へ開きます。対象planetの個別ショートカットは不要です。

対象planetを削除した場合は、開くplanetを選び直してください。

## 4. アプリごとに切り替える・無効にする

「アプリ」タブで、起動中のアプリから選ぶか、実行ファイルを指定します。横の「表示するplanet」を選び、「＋追加」して保存します。

指定したアプリが前面にある間は、そのplanetを優先して開きます。この場合、中央のホイールでは別のplanetへ切り替えません。

操作内容もアプリ専用にする場合は、「planetを専用設定にする」「orbitを専用設定にする」を使います。初回は共通設定のコピーから編集します。専用設定をOFFにしても内容は残り、再びONにすると使えます。専用設定のないアプリでは共通設定を使います。

「アプリ → ブラックリスト」では、planet・orbitを使わないアプリを登録できます。機能ごとにON・OFFを指定して保存します。アプリ全体で機能をOFFにしている場合は、アプリ別にONにしても動作しません。

## 5. ファイルをドラッグして変換する

1. ファイルを左ボタンでつかみ、ドラッグを始めます。
2. つかんだままplanetの呼び出しキーを押します。
3. ファイルの種類に対応した変換先が表示されます。
4. 目的の項目の上で左ボタンを離すと変換します。

元ファイルは残し、同じフォルダーに結果を保存します。同名のファイルがある場合は連番を付けます。元の場所が分からない場合や、異なる場所のファイルをまとめて変換する場合は、その都度保存先を尋ねます。

中央や変換先のない場所で離す、またはEscを押すとキャンセルします。

### 対応する変換

| 入力 | 主な変換・操作 |
| --- | --- |
| 画像（HEIC・HEIF・AVIF・SVGを含む） | PDF・PNG・JPEG・WebP・TIFF・BMP・GIF・ICO、文字認識 |
| PDF | ページごとの画像化・分割、複数PDFの結合、文字認識 |
| Word：DOC・DOCX・ODT・RTF | PDF・UTF-8のTXT・DOCX |
| Excel：XLS・XLSX・ODS | PDF・シートごとのUTF-8 CSV／TSV |
| PowerPoint：PPT・PPTX・ODP | PDF・スライドごとのPNG／JPEG |
| ファイル・フォルダー | ZIPに圧縮 |
| ZIP | フォルダーへ展開 |

Office文書の変換には、対応するMicrosoft Officeアプリ、またはLibreOfficeが必要です。追加した後はOrbitalsを再起動してください。どちらもない場合、文書をドラッグしたときはZIP圧縮のみを表示します。LibreOfficeではレイアウトが異なる場合があります。

- 複数画像をPDFにすると、1つのPDFにまとめます。PDFの画像化ではページごとに保存します。
- CSV／TSVにはセルの表示内容を保存し、書式・数式・画像は残りません。
- 「TXT」は認識した文字を保存し、「文字をコピー」はクリップボードへコピーします。
- 複数のファイル・フォルダーをZIPにすると1つにまとめます。ZIPの展開はパスワードのないものに対応します。

### 変換先をカスタマイズする

「変換」タブで入力の種類を選びます。ドラッグで並べ替え、「＋ 変換先を追加」で増やし、右クリック →「消去」で削除します。入力の種類ごとに32件まで登録でき、数に応じて均等に並びます。

項目を選ぶと、名前・表示／非表示・画質・長辺の上限・解像度などを変更できます。同じ形式を複数登録し、画質などを変えて使い分けることもできます。「保存」で反映します。

### 履歴とPDFの詳細操作

歯車 →「起動・管理」→「ドラッグして変換」から「変換の履歴」を開けます。処理の中止、保存先やエラーの確認に使えます。履歴はアプリを終了すると消えます。

「PDFの結合・ページ抽出など」では、ファイルの順番や対象ページを指定できます。対象ページは `1,3-5` のように入力します。

### 形式による注意点

- GIFと複数ページの画像は先頭の画像を使い、GIFの出力は静止画になります。
- JPEG・BMPでは透明部分が白になります。
- SVGは、外部ファイルやWeb上の画像・書体への参照には対応しません。画像を埋め込み、書体をパスに変換してください。
- 1回の入力は128ファイル・合計512MBまでです。ZIP内は10,000件・合計512MBまで、PDFの画像化は1回に1,000ファイルまでです。
- 画像とPDFなど、異なる種類を混ぜた入力は変換できません。画像を直接ドラッグできないアプリでは、いったんファイルに保存してください。

## 6. アクションとマクロ

キー入力、キー保持、ファイル・フォルダー・URL、アプリ起動、定型文、タブ操作、ウィンドウ配置、音量・マイク操作などを割り当てられます。一覧は用途別に分類してあり、検索も使えます。

### アプリ・ショートカットを開く

「アプリを起動 / 前面へ」では、exeまたはWindowsショートカット（.lnk）を指定できます。プライベートモードなど特定の起動方法を使う場合は、そのショートカットを選んでください。exeを直接指定すると、起動済みのウィンドウを前面へ移します。

### トグルとお気に入り

「トグル」は押すたびに次の段階へ進みます。各段階の操作・名前を指定し、「＋」で増やせます。音量・マイクのミュートは、実際の状態を表示に反映します。通常のトグルは登録した順番で切り替わり、他アプリで変えた状態には追従しません。

配置した項目の「お気に入りに保存」で、設定した操作を再利用できます。お気に入りから配置した項目は、それぞれ独立して編集できます。

### マクロを作る

マクロは登録順に操作を実行します。「追加するステップ」から選び、「＋ ステップを追加」で組み合わせます。

| ステップ | 使い方 |
| --- | --- |
| キー・時間を待つ | 記録したキーを送る、または指定時間だけ待ちます。 |
| アプリ起動・ファイルを開く | アプリ、ショートカット、ファイル、URLなどを開きます。 |
| 操作先のウィンドウを待つ | 実行ファイル名やタイトルの一部を指定し、そのウィンドウが前面に出るまで待ちます。 |
| 文字を入力 | 文章を入力します。`{date}`、`{time}`、`{datetime}`、`{clipboard}` を日付・時刻・開始時のクリップボード文字に置き換えられます。 |
| ウィンドウ・音声・Windows設定 | サイズ・配置、音量・マイク・出力先の変更などを組み合わせます。 |

アプリ起動の後にキー入力などを続ける場合は、「操作先のウィンドウを待つ」を入れてください。指定時間内に見つからない場合は中止します。

「このステップを試す」「ここから試す」で一部だけ確認できます。3秒以内に操作先のアプリへ移ってください。Escで中止できます。条件待ち以外で操作先が変わると停止します。

マクロは64ステップまで、指定した待ち時間とウィンドウ待ちの上限は合計60秒までです。

### 連続したキー操作を記録する

「連続したキー操作を記録」を押すと、3秒後に記録を始めます。操作先へ移り、終わったらF12または「完了」を押します。Escまたは「中止」で取り消します。

キーの組み合わせと待ち時間を記録します。マウス操作や文章の文字起こしは含みません。記録後に各ステップを編集し、保存できます。

## 7. 外観・表示を変える

右上の歯車 →「外観」で、リング全体・ボタンのサイズ、色・濃さ、弧状スタックの間隔、表示演出、ジェスチャーの線などを調整します。見本を確認して「保存」で反映します。

- **文字のみを表示**：通常・スタック・変換のリングに、アイコンの代わりに名前を表示します。
- **登録済みアクションを均等に配置**：未割り当ての枠を省き、登録数に合わせて並べます。OFFに戻すと元の配置に戻ります。弧状スタックの並びは変わりません。
- **表示演出**：リングを開くときとplanetを切り替えるときで、個別にON・OFFを指定できます。

項目ごとの見た目は、配置した項目の「アイコン・文字列を変更」から変更します。一覧から選ぶ、自分の画像を使う、短い文字列を表示する方法があります。トグルやミュートでは状態ごとの表示も指定できます。

自作画像はPNG・JPEG・ICO・BMP・GIFに対応します。元画像は4MB以内・縦横4096px以内で、GIFは静止画になります。取り込み後は元画像を移動しても使えます。orbitでは形を表示するため、この設定はplanet用です。

## 8. バックアップ・更新・アンインストール

### バックアップと復元

歯車 →「起動・管理」の「バックアップを保存」で、配置・ジェスチャー・アプリ別設定などをJSONファイルに保存します。

「バックアップから復元」で読み込み、内容を確認して「保存」で反映します。別のPCへ移す場合は、登録したアプリやファイルの場所を合わせてください。

### 更新

歯車の左隣にある「更新の確認」を押します。新しい版があれば、ダウンロードページを開けます。

更新時は常駐中のOrbitalsを終了し、新しいセットアップを実行します。保存済みの設定は引き継ぎます。ポータブル版では、既存の `settings.json` を残して配布ファイルを差し替えてください。

### アンインストール

インストーラー版は、Windowsの「インストールされているアプリ」から削除します。設定は残るため、再インストール時にも使えます。設定の保存先は `%LOCALAPPDATA%\Orbitals` です。

ポータブル版は展開したフォルダーを削除します。設定も同じ場所にあるため、必要なら先にバックアップしてください。

## 9. うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| リングやジェスチャーが反応しない | 一時停止中でないか、歯車 →「操作」で機能がONか、ブラックリストに登録していないか確認します。 |
| 編集した内容が実際の操作に反映されない | 「保存」を押したか確認します。下書きは実際の操作に反映しません。 |
| ジェスチャーが違う操作になる | 登録した動きの始点と向き、折り返しの有無を確認し、認識テストや「許容するずれ」で調整します。 |
| 右ボタンのジェスチャーが競合する | StrokesPlus.netなど、同じボタンで操作するアプリを停止するか、開始ボタンを分けます。 |
| 特定のアプリへキー入力が届かない | 管理者権限で動くアプリには入力できない場合があります。 |
| Office文書の変換が出ない | 対応するOfficeアプリまたはLibreOfficeをインストールし、Orbitalsを再起動します。 |
| 呼び出しキーを登録できない | Windowsの予約キーや他アプリとの重複を避けて、別の組み合わせを試します。 |

自作の連携機能を追加する場合は、[プラグインの作り方](プラグインの作り方.md)を参照してください。
